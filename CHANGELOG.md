## 1.1.1

### New
- Added support for **Minecraft 26.3 on NeoForge** (requires NeoForge 26.3.0.23-beta or newer).
- The mod is now also published on **CurseForge**.

### Fixes
- The mod icon is now shown in NeoForge's mod list (on 26.3 via the new `iconFile` property).

## 1.1.0

### New
- Added support for **Minecraft 26.3** (Fabric). NeoForge 26.3 will follow as soon as NeoForge publishes a 26.3 build.

### Changes
- Updated dependencies for all supported versions:
  - Fabric Loader 0.19.5 (now the minimum required version), Fabric API and Fabric Language Kotlin 1.14.1
  - NeoForge 26.2 now builds against the stable NeoForge release, and Kotlin for Forge 6.3.0 is used for all NeoForge versions
  - Sodium config integration built against Sodium 0.9.2
